## 📂 Project Directory

### 1. Cybersecurity — Task 1: Basic Network Scanning with Nmap

**Project folder:** `CyberSecurity-Task1-BasicNetworkScanning/`

This project explores basic network scanning and service detection using Nmap in a Kali Linux environment.

**Objectives:**
- Perform basic TCP port scanning.
- Explore service and version detection.
- Attempt operating system detection.
- Test service detection using a controlled local HTTP server.
- Save scan results and document the findings.
- Practise responsible and authorized security testing.

**Tools and technologies:**
- Kali Linux
- Nmap
- Python
- Git and GitHub

**Key learning outcomes:**
- Understanding open and closed TCP ports.
- Interpreting Nmap scan results.
- Identifying services running on open ports.
- Understanding the limitations of operating system detection.
- Documenting technical findings for review.

**Project documentation:** [View the project folder](./CyberSecurity-Task1-BasicNetworkScanning/)
